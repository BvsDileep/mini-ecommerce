# Mini E-commerce

A minimal e-commerce application with two pages:

- **Cards Page**: Displays a list/grid of product cards.
- **Details Page**: Shows detailed information about a selected product.

## 🔗 Repository

[https://github.com/BvsDileep/mini-ecommerce.git](https://github.com/BvsDileep/mini-ecommerce.git)

## 🚀 Getting Started

Follow the steps below to set up and run the project locally:

### 1. Clone the Repository

```bash
git clone https://github.com/BvsDileep/mini-ecommerce.git
```

### 2. 2. Navigate to the Project Directory

```bash
cd mini-ecommerce
```

### 3. Checkout to the Develop Branch

```bash
git checkout develop
```

### 4. Install Dependencies

```bash
npm install
```

### 5. Run the Project

```bash
npm start
```
